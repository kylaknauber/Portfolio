# Portfolio

This project is a simple portfolio webiste created in React. This application includes links to my resume, my contact information, and a few of my most notable projects. There is also information on my programming background, education, skills, and courses I have completed. The section containing the projects include interactive links/photos for a glimpse into each application

## React used in combination with Vite

To run this application, first make sure that Node.js installed on your local machine, with a version of 22.17.0 or later. Next, navigate to a directory in which you want to contain this repository, then clone this repository. Navigate to the repository directory and make sure you can see the "src" folder, but are NOT INSIDE the "src" folder. Run the command "npm install" to install Node Modules, then run the command "npm run dev" to start the application.
